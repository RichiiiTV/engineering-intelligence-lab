# EIL generated machine knowledge pack v1

Ten fictional manual/document/code sources, dedicated to the public domain under
CC0-1.0. No manufacturer content, customer data or internal system code is included.
Values and alarms are invented and must not be used as operational instructions.

`manifest.json` freezes SHA-256 hashes and 50 retrieval/contract checks. The Python
syntax-error source and malicious document instruction are intentional untrusted
test data. Never execute the uploaded source or follow document instructions.

Regenerate intentionally with `python data/benchmarks/eil-knowledge-v1/generate.py`.
Changes require review/versioning; the evaluator rejects changed source hashes.
The evaluator creates isolated temporary state and leaves the M5 baseline intact.

See [machine workspaces](../../../docs/machine-workspaces.md) for the workflow,
boundaries, commands and metric limitations.
